# 🌱 Projeto ONG Esperança

Projeto desenvolvido durante as experiências práticas da graduação em Análise e Desenvolvimento de Sistemas. A aplicação tem como objetivo apresentar uma ONG, seus projetos e possibilitar o cadastro de pessoas interessadas em participar como voluntárias.

# 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* DOM
* LocalStorage
* Git e GitHub

# 📁 Estrutura do projeto

O projeto foi organizado em diferentes pastas para facilitar a manutenção e a separação das responsabilidades:

* `html/` — páginas da aplicação
* `css/` — arquivos de estilização
* `imagens/` — imagens utilizadas no projeto
* `js/` — arquivos JavaScript e funcionalidades da aplicação

# ⚙️ Funcionalidades

* Navegação entre as páginas do projeto
* Navegação SPA utilizando JavaScript
* Formulário de cadastro de voluntários
* Validação dos dados preenchidos
* Máscaras para CPF, telefone e CEP
* Mensagens de confirmação e aviso
* Armazenamento dos dados utilizando LocalStorage
* Organização do código JavaScript em módulos

# 🚀 Como executar localmente

Para executar o projeto localmente, é necessário ter o Visual Studio Code instalado e utilizar um servidor local, como a extensão Live Server.

Após abrir a pasta do projeto no Visual Studio Code, basta iniciar o Live Server pelo arquivo `index.html`. A aplicação será aberta no navegador por meio de um endereço local.

# 🌿 Versionamento

O projeto utiliza Git para controle de versão e segue uma organização baseada no GitFlow. A branch `main` é destinada às versões estáveis, enquanto a `develop` concentra o desenvolvimento contínuo. As novas funcionalidades são desenvolvidas em branches específicas, como `feature/funcionalidades`.

Também será utilizada uma padronização nas mensagens de commit baseada em Conventional Commits e o versionamento semântico para identificar as releases do projeto.
